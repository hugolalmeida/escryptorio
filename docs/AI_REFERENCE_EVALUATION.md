# Referências externas · avaliação de conceitos

Consulta das páginas oficiais e arquivos de licença em 14/11/2026. A análise é de documentação e fontes acessíveis; não houve instalação, execução, auditoria integral de segurança nem comprovação independente das alegações dos projetos. Páginas de branch principal são mutáveis; a API de metadados/commit do GitHub não ficou acessível nesta consulta, portanto os SHAs das referências **não foram fixados**.

| Referência / conceito | Benefício possível | Complexidade / custo estimado | Risco | Licença verificada | Aplicabilidade e decisão |
| --- | --- | --- | --- | --- | --- |
| [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading): comitê Bull/Bear, evidências e histórico versionado, referência ao backtest | Contrapontos e rastreabilidade | Alta; múltiplos modelos, ferramentas, dados e operação; custo monetário não medido | README declara fallback entre provedores, broker e live; dados e autorizações não equivalem ao CryptoLab | [MIT](https://raw.githubusercontent.com/HKUDS/Vibe-Trading/main/LICENSE), exige preservar aviso em cópias substanciais | **Aproveitar conceito**, reinterpretar referências e teses; **adiar** comitê; **rejeitar** fallback de dados, brokers e execução. README descreve capacidades, não prova segurança. |
| [AutoHedge](https://github.com/The-Swarm-Corporation/AutoHedge): diretor → quant → risco → execução, saída estruturada e logs | Separar investigação quantitativa e revisão de risco | Alta; agentes Swarms, modelos e integrações; custo não medido | README descreve negociação autônoma Solana e chave de carteira; auditoria financeira não é comprovada só pelo nome Risk Manager | [MIT](https://raw.githubusercontent.com/The-Swarm-Corporation/AutoHedge/main/LICENSE) | **Reinterpretar** responsabilidade quant/risco e evidências; **rejeitar** agente executor, carteira, sizing operacional e fluxo automatizado. Handoffs e logs detalhados não foram auditados no código. |
| [FinceptTerminal](https://github.com/Fincept-Corporation/FinceptTerminal): terminal de dados e pesquisa, conectores e visualização | Separação de fontes, análise e apresentação | Muito alta para CryptoLab: C++20/Qt6, Python embutido, conectores e manutenção; custo não medido | Conectores, modelos e broker ampliam fronteiras; proveniência e arquitetura específica de agentes não foram auditadas | [AGPL-3.0-or-later](https://github.com/Fincept-Corporation/FinceptTerminal#license), [texto AGPL v3](https://raw.githubusercontent.com/Fincept-Corporation/FinceptTerminal/main/LICENSE) | **Aproveitar conceito** de rastreabilidade e layout informativo; **adiar/rejeitar** importação do terminal, conectores e código. Revisão jurídica específica seria necessária antes de reutilizar código; uso de ideias não equivale a copiar. |

As licenças foram verificadas na raiz, não cada dependência ou asset. MIT não autoriza ignorar suas condições; AGPL é copyleft e obrigações concretas dependem do uso. Este estudo não é parecer jurídico. O README do Fincept distingue edição open source de Enterprise e menciona modelos por chave própria; não atribuímos recursos da edição proprietária ao repositório público.
