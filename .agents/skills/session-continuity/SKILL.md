# Continuidade
Ao retomar, leia AGENTS.md e o handoff disponível; confira branch, HEAD, status, diff e documentação antes de usar relatos anteriores. Separe fatos verificados de hipóteses e pendências. Para entregas de múltiplas etapas, registre no handoff o escopo, referência Git, testes realmente executados, bloqueios e próximo passo. Não inclua segredos. O handoff não é autorização nem substitui Git ou testes. Commits seguem AGENTS.md.
