# Testes web
Defina cenários proporcionais ao risco; use fixtures isoladas e localizadores acessíveis, aguardando condições em vez de pausas fixas. Cubra estados de carregamento, erro, concorrência e teclado quando pertinentes, incluindo desktop e mobile. Não dependa de dados públicos atuais para a suíte normal. Relate comandos, resultados e casos não testados.
