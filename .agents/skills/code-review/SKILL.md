# Revisão de código
Compare diff e requisitos; priorize segurança, integridade, concorrência, limites e compatibilidade. Diferencie falha comprovada de hipótese e preferência. Para cada achado, registre evidência, impacto, arquivo e teste de regressão proporcional. Preserve alterações preexistentes.
